# 📚 NimmaGuru – Android App

A modern Android application built to manage student and teacher information in a structured and efficient way. It helps you store, update, and track academic data with a clean and fast system.

---

## 🚀 Features

• 🔐 Secure login and logout system
• 👤 Student profile creation and updates
• 🧑‍🏫 Teacher profile management
• 📊 Professional dashboard with overview data
• 🗂️ Add, edit, and delete records
• 🔍 Search and filter functionality
• ⚙️ Settings and profile update module
• 💾 Offline data storage using local database
• ⚡ Fast and smooth performance

---

## 🛠️ Tech Stack

• Language: Java or Kotlin
• Platform: Android Studio
• Database: SQLite or Room Database
• UI: Material Design components
• Architecture: MVVM

---

## 📂 Project Structure

com.example.nimmaguru

ui/ → Activities and UI logic
data/ → Models and database handling
adapter/ → RecyclerView adapters
utils/ → Helper and utility classes

## ⚙️ Setup Instructions


### Download ZIP

1. Open the repository on GitHub
2. Click Code
3. Click Download ZIP
4. Extract the ZIP file
5. Open the extracted folder

---

### Import into Android Studio

1. Open Android Studio
2. Click Open
3. Select project folder
4. Wait for Gradle sync
5. Click Run

---

## 🎯 Purpose

This app helps you manage academic records in one place. You can organize student and teacher data, update profiles, and maintain structured information without internet dependency.
